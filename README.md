# UniBot

Build AI Chatbots for Support & Teams

Create custom AI chatbots for customer support and internal teams. Train on your data and embed anywhere. No coding required.

## 🚀 Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:4321](http://localhost:4321)

## 🛠️ Tech Stack

- **Astro** - Static site generator
- **Tailwind CSS v4** - Styling
- **TypeScript** - Type safety
- **Supabase** - Lead capture database
- **Cloudflare Pages** - Deployment

## 📦 Commands

| Command | Action |
|:--------|:-------|
| `npm run dev` | Start dev server at `localhost:4321` |
| `npm run build` | Build for production |
| `npm run preview` | Preview production build |

## 🌐 Deployment

Deploy to Cloudflare Pages:
```bash
npm run build
wrangler pages deploy dist --project-name=unibot
```
